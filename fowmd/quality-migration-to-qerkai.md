# 降智检测迁移到 Qerkai

- Qerkai 负责题库、定时答题、最近 3 条模型日志检查、连续异常与恢复计数、结果和历史。
- 本项目只调用 `/api/v1/admin/account-quality/results`，每批最多 100 个账号，批次串行；接口使用现有 Sub2 管理员认证。不传代理、不调用单账号测试或日志探测接口。
- 设置保留在“降智检测设置”：轮询间隔默认 60 秒，结果有效期默认 900 秒，可以选答题异常、模型不一致，以及任一/同时满足。仅处理 Qerkai 已确认异常。
- 动作保留母号强制踢出或切组，可自动恢复分组；原母号锁、操作间隔、子号锁、轮转周期校验不变。
- 重复结果不累计次数或重复完成动作；失败动作可重试。接口失败、未知、过期、旧推送/旧轮转周期的证据不会触发处理。已经实际移出但下游清理未结束的任务仍可完成清理。
- 原题库与参数仍在本地数据库中，可导出 JSON 到 Qerkai 导入，不覆盖原数据。先部署 Qerkai，再部署两个 space；Qerkai 默认关闭探测，需在“公告”上方的新页面保存并启用。
- 账号流程状态显示答题和模型结果；顶部倒计时现在表示“降智结果查询”，不是本地探测。

当前默认糖果题允许提前决定两种形状各取多少，答案为 21。原不允许挑选形状的旧题答案为 29；导入自定义题目时保持题目与答案配套。
