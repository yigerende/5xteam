# SIWC 网页额度恢复（2026-11-12）

全自动付款完成并推送原 SIWC 账号后，在额度步骤新建密码/2FA 网页登录，取得付款后的网页 AT。SIWC RT/AT 不可用于网页额度接口。两种 SIWC 授权来源均使用此额度恢复路径。

Space 只把 siwc_web_access_token、siwc_web_account_id 增量更新给原 s2 account ID，随后 POST /api/v1/admin/siwc/accounts/{id}/usage 刷新；定时查询继续 GET 同接口。普通额度轮询不反复登录，网页凭证缺失、到期或明确网页401时才恢复。管理端认证401、普通网络错误、解析失败不触发账号重登。

新网页凭证及同步状态加密持久化；同步失败下轮仅重试同步。登录失败至少间隔60秒或更长的额度配置间隔。登录调用现有代理选择/冷却机制，独立4分钟上限；不经过会删除登录失败账号的邮件管理路由。登录结果校验邮箱、空间、有效期及新旧AT；停止版本、下游绑定变化时丢弃旧结果。持锁重读凭证并仅更新网页字段，保留并发续期的 SIWC RT/AT。

不重付、不重做SIWC授权、不新建下游账号、不改变分组/代理/原推送时间。支持只返回5h或7d的SIWC额度，未返回窗口保持nil；只对真实有效且已启用窗口判断阈值。普通下游仍须有7d。

验证：真实指定账号重新网页登录后网页额度HTTP200（原AT 401），只提供7d。隔离回归覆盖一次重登、后续查询、401节流、同步断线恢复、错账号/旧token/绑定改变、并发SIWC续期及7d-only落库；相关HTTP/Store/Sub2回归与vet通过。
