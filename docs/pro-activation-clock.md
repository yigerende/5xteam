# Pro 推送时长从开通起算

- 新开通成功后，在成功订单同一事务中将 `succeeded_at` 写入账号 `pro_push_started_at`，标记 `pro_push_started_source=activation`。不等待授权、推送或首次额度查询。适用于自动补货、手动全自动、单独开通及全部付款供应商。
- 付款失败、结果未知、仍在处理中不启动计时；旧订单不得启动另一条全自动链的计时。重复回调、推送、换目标、凭据导入及重启不改已记录起点。
- 已付款续跑且缺少起点时，用当前成功订单恢复；历史订单缺少成功时间时使用原开通步骤时间或订单成功更新时间。没有本地成功订单的外部账号仍在首次推送成功时起算。已存在起点的历史账号不批量回写。
- 页面标明“开通时间起算”；历史或外部账号保留来源说明。真实授权、推送完成时间照常记录。
- 推送时限、到期收尾及补货的到期预测沿用同一起点；尚未推送成功、运行中、停止或暂停等原执行限制不变。代理定时解绑仍按实际绑定时间起算。
- 成功落库只查询当前账号，缺失计时的续跑只查该账号订单；不新增周期性历史扫描或上游调用。

验证覆盖成功/失败/未知付款、付款后授权失败、跨供应商完整自动流程、并发回调与重复推送、历史/外部账号、事务回滚、到期但尚未推送，以及原 SIWC、补货和代理解绑回归。
