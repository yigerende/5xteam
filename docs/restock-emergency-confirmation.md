# 紧急补货仍需连续确认（2026-11-24）

并发压力和退出前补货均按配置的连续确认次数执行，包括实际容量不足、账号侧紧急排队、确定到期和已达到额度退出阈值。紧急状态只影响确认后的冷却选择，不再直接批准新增数量。

- 缺至少1个、2个分别累计独立新采样；第1个确认完成不能批准第2个。
- 同一份快照或额度缓存不增加次数；条件回落清零，重新达到从第1次开始。
- 配置为3次时，第3个连续有效样本才可补货；配置为1次则允许首个有效样本触发。
- 旧版快照中“只确认1次却已批准2个”的紧急结果必须重新核对逐数量次数，不能在重启或重复评估时沿用提前放行。
- 补后目标利用率、数量上限、预算、熔断、批次等待和普通/紧急冷却仍使用原配置。预计支撑、平均时限接替、最低备用及空组启动保持各自规则。
