# 额度登录沿用原代理会话

全自动每次建立连续登录时，将实际生成的完整代理会话地址加密保存，绑定邮箱和本轮流程 ID。额度需要重新登录获取付款后的新网页 AT 时，直接使用这条地址，不重新生成厂商 session，不因为全局配置改动而换线。密码和 2FA 仍正常验证，网页客户端重新建立；复用的是代理会话。

额度登录失败按原额度重试间隔再次使用同一地址；正常额度轮询及网页 AT 同步失败不重复登录。初始登录整轮重试或主备故障切换仍按原规则生成新会话并替换本轮保存值，后续额度跟随最终成功的登录会话。新订单、不同邮箱隔离；旧流程/停止后的迟到写入被拒绝。代理地址不进入账号响应或日志，删除邮箱时自动清理加密记录，服务重启后可恢复。

历史订单没有保存原厂商会话标识，无法仅靠出口 IP 还原原代理地址，继续旧登录方式并记录兼容提示。新增订单完整生效。保留 60 分钟等既有厂商参数；供应商会话过期或出口故障时不能由 Space 保证物理出口 IP 永久不变。

验证包括三厂商实际 Go 连续登录及额度登录入口、隔离 Python 子进程、故障后再次额度登录、期间修改全局代理、正常轮询不重登、数据库重启恢复/加密、不同流程隔离、停止后迟到写入及删除清理；付款、推送与额度凭证同步回归继续通过。
