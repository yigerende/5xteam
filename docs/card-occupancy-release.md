# 未开通记录删除与占用处理

EJH、环球账号回款中的删除未开通记录，表示操作员已经核实该笔未开通。对于已停止的 failed、manual_review、submission_unknown 原订单，删除事务同时保存 not_activated 核实结果、结束原单并释放该订单的卡片占用，原账号、加密请求快照、供应商响应及资金记录保留。

付款执行中、自动流程/补货任务仍运行、供应商正在核实，或已有付款成功/交易证据的记录不会被强制结束。应先结束正在执行的任务或处理实际付款结果。批量删除会保留这些记录；并发的账号请求会收到冲突提示，不能在付款提交过程中抢占卡片。

卡片占用区域的“处理占用”入口对未删除的异常账号同样显示，可查询原订单并填写人工核实依据。正常成功账号保持回款后释放规则。人工将成功记录归为未开通的既有展示逻辑不改写原付款成功事实。

已核实未开通的订单停止自动轮询，手动刷新也返回保存的核实结果；迟到的旧状态不能恢复占用。重复删除、重启恢复只处理对应原订单，不解除其他账号或新订单。启动时修复历史上明确删除过未开通记录、但未结束原单的情况；仅删除账号管理记录不作为自动核实依据。

相关验证：Go 的 CardCaseDeletion、DeleteEJH、NexovccDelete、EJHDelete、EJHResolve、NexovccResolve 测试，以及 `frontend/scripts/check-card-occupancy-render.mjs`、`check-nexovcc-case-delete.mjs`。
