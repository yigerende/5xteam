# Sub2Api 数据与客户端对账

Space 主动从客户端 PostgreSQL 读取明细，存入独立 `client-audit.db`，不修改 sub2api 项目、容器、数据库结构或业务数据。接入并非管理员 HTTP API。数据库密码通过 Space 既有主密钥加密保存；接口不回传密码。

## 只读边界

所有源连接设置 `default_transaction_read_only=on`，每次查询使用 `REPEATABLE READ READ ONLY` 事务，结束回滚。固定表与字段白名单，只执行 SELECT 和事务局部资源配置，不提供任意 SQL 输入。原始 Key、密码、OAuth Token、用户提示词、请求体及 IP 不同步。每轮一个任务、串行小批量读取，限制查询超时、锁等待、内存、并行查询和批次间隔；只读查询仍会消耗少量数据库资源。

## 增量同步

使用记录、计费凭据、资金流水、支付状态和管理审计按时间＋ID游标同步。支付按更新时间、充值按使用时间读取。单轮目标固定，跨轮及重启续传；各表轮转避免大表挤占小表。回扫近期范围补齐延迟落库，按数据源＋实体＋ID幂等更新，并修正本地日汇总。保存设置不立即同步，立即同步与历史补录单独执行。停止本轮保留断点；关闭自动同步阻止以后周期运行。

用户、Key、套餐是小表一致快照；Key和套餐变化保存历史。源地址、端口、库名决定数据源身份，修改展示名称或网站地址不清空进度。首次默认只取今天，历史补录在明细保留期内执行。明细压缩保存，过期分批删除；日汇总保留。永久清理边界阻止回扫已清理明细造成重复累计，已清理范围不能直接补录。

## 用户账户及余额快照

当前用户可筛选“已启用且余额大于0”，同时显示余额、冻结余额及上游累计充值字段。历史余额快照只包含快照时状态 active、余额大于0且未删除的用户，保存当时邮箱、余额和时间，可导出 CSV。默认每小时保存一次、保留180天；使用同步得到的独立用户快照，不增加源端查询。不会自动恢复或回写余额。页面历史选择器列出最近200份，较早快照仍保留在本地，可通过余额接口的 at 参数读取。

## 对账证据

核对零费用用量、负费用、费用倍率、请求与Key归属、双向计费凭据缺失、Key耗尽快照后继续用量和独立余额变化。凭据缺失先标候选，再每轮最多50项按唯一请求ID＋Key定点查询，包含归档计费表。充值、赠送、管理员调整、返利转入分别保留证据；返利仅 transfer 计入钱包，支付退款标待核实而不重复当充值入账。

金额按10位小数整数计算。倍率检查固定容差0.000001 USD；可配置金额容差用于余额快照核对。余额比较包含冻结余额，仅使用源用户最后更新早于已结算水位的独立快照，快照至少间隔5分钟；不能用消费倒推期初余额作为证明。大批补录、源端查询失败、持续活跃未结算或缺乏快照时显示证据不足。历史补录清除旧对账基线，重新建立独立快照。

“需核实”是线索，不是用户恶意结论；“快照区间一致”只对显示的快照区间有效。免费倍率、免费 Fast、套餐、退款、在途结算及管理员调整需结合明细判断。未被上游记录的请求、回扫范围外的迟到数据和超保留范围证据无法凭此页面保证完全发现。页面不自动补扣、退款、封号或调额度。

## 页面与默认操作

Sub2Api 包含客户端对账、用户账户、使用记录、同步记录和连接与同步设置。页面筛选、导出、详情全部查询 Space 本地副本。同步状态显示目标、数据水位、断点及最近30轮运行结果；源连接错误不影响 Space 原有业务。部署前先测试只读连接，再开启自动同步；两套 Space 独立配置、独立保存。
