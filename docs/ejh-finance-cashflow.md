# EJH 成本统计与退款冲回

成本页使用北京时间和流水实际入账日期。消费收益、退款前成本、退款冲回分别展示：净利润 = 消费收益 − 退款前成本 + 退款冲回。跨天退款不改写原消费日期，销卡退回主余额不再形成一次收益。

当前 MASTER_B1_5 的成功清算退款在销卡前不恢复可用卡余额，按成功退款流水的 USD refundBuyPrice 单列“退款待销卡结算”。卡片已销卡后移出该项，由最新主余额体现。缺少金额时显示待核实，其他卡产品不推断同样规则。此项只补充资金资产核对，不修改余额、订单或已记录成本。

旧下游消费异常只影响其起止日期覆盖的周期，历史累计金额保留。活动账号尚未按日核对完成、缺失金额或无明确日期的数据继续提示不完整，不伪造最终利润；全部统计仍使用原累计消费口径。

性能：成本页读取既有 overview 增量接口及 finance?snapshots=none。后者使用独立只读数据库快照，并跳过历史大快照的读取和解密；原 finance 默认接口仍兼容。计算移入 Web Worker，同一批数据只准备一次，切换周期复用计算材料；页面退出取消请求和定时器。

验证覆盖跨天/重复/部分退款、销卡前后资产转移、缺失金额、旧期间异常隔离、累计与分期口径、Worker 计算复用，以及紧凑接口不读取损坏旧快照。真实规模数据经过桌面及手机页面验证，不调用上游付款、退款、销卡操作。
